### 📋 [Request Management System](https://github.com/yigittgulbeyaz/request-management-system) — *built during a 30-day internship*

Workflow automation platform that turns plain-language customer requests into scored, tracked development tasks.

- 🔄 Four-role workflow: **Customer → Product Owner → Developer → Admin**
- 📊 Automatic priority derivation and deadline bands from impact & urgency scoring
- 🧾 Full audit trail on every state change
- 🔒 Access control enforced at both view and service layers
- ⚙️ Atomic transactions, row-level locking and DB projections for concurrency & performance
- 🧭 State machine encoded in enums so DB and UI can't drift apart

`Java 21` `Spring Boot 4.1` `Vaadin 25` `Oracle DB` `PL/SQL`
